# machine-learning-kmeans-perceptron-project

This project contains three machine learning tasks implemented in Python using Jupyter Notebook.

## Project Tasks

### Task 1: Network Connection Classification
- Used a sample KDD dataset.
- Balanced normal and anomaly records.
- Split the dataset into training and testing sets.
- Trained a Single Perceptron classifier.
- Applied K-Means clustering with different values of k.
- Used cluster centroids for classification and measured accuracy.

### Task 2: Customer Segmentation
- Used mall customer data.
- Standardized numerical features.
- Encoded categorical features using one-hot encoding.
- Applied K-Means clustering for customer segmentation.
- Analyzed average spending, income level, and loyalty points for each cluster.

### Task 3: Image Segmentation
- Used K-Means clustering for plant image segmentation.
- Treated each RGB pixel as a data point.
- Generated segmented images for different cluster values: k = 2, 3, 4, and 5.
